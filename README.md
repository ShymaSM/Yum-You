# 🍴 Yum & You – Food Ordering Website

## 📌 About

**Yum & You** is a responsive online food menu and ordering website.

The website allows customers to view the available food items, add products to a shopping cart, enter their details, and place an order online.

### Tagline

> Your choice, we provide. ❤️

---

## ✨ Features

- Responsive food menu
- Yum & You branding and logo
- Snacks & More section
- Juices section
- Add to Cart functionality
- Floating Cart icon
- Increase/decrease item quantity
- Remove items from cart
- Automatic total price calculation
- Customer name collection
- Mobile number collection
- Order date and time
- Customer special request/message
- Place Order functionality
- Email order submission
- Mobile-friendly design
- Modern food-themed UI

## 🛒 Customer Order Flow

The customer can use the website in the following way:

```text
Open Website
      ↓
View Menu
      ↓
Select Food
      ↓
Click "+" Add to Cart
      ↓
Continue Shopping
      ↓
Click Cart Icon
      ↓
View Selected Items
      ↓
Change Quantity / Remove Items
      ↓
Enter Customer Details
      ↓
Enter Special Request
      ↓
Click "Place Order"
      ↓
Order Submitted
      ↓
Order Received by Email
